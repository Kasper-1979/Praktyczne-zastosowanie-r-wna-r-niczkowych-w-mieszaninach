# Project Presentation

## 📌 Overview
This directory contains the slide deck used to present the project "Praktyczne zastosowanie równań różniczkowych w mieszaninach" (Practical application of differential equations in mixtures). 

The presentation summarizes the mathematical concepts, real-world applications, and computational results of the project, and was prepared by Kacper Lis.

## 📄 File Contents
To ensure maximum compatibility, the presentation is provided in two formats:
*   **`presentation_PL.pdf`**: A static, easily viewable PDF version of the slide deck.
*   **`presentation_PL.pptx`**: The original editable PowerPoint presentation file.

## 📊 Presentation Structure
The slide deck walks the audience through the following topics:
*   **Industrial Applications:** An overview of how differential equations are used in the chemical industry, water purification, gas transformations, and biochemical processes.
*   **Problem Statements:** Clear definitions of the two analyzed examples: the 1500-gallon brine tank (Example 1) and the 1000-gallon piece-wise pollutant retention tank (Example 2).
*   **Computational Implementations:** Snippets and explanations of the wxMaxima analytical solution and the Python numerical code.
*   **Data Visualization:** Graphs and animation frames demonstrating the change in substance concentration over time for both scenarios.

*(Note: The presentation slides are written in Polish).*
