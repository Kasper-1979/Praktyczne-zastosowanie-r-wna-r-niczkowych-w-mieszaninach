# Project Reports

## 📌 Overview
This directory contains the main theoretical document for the project, titled "Praktyczne zastosowanie równań różniczkowych w mieszaninach" (Practical application of differential equations in mixtures)[cite: 5]. 

The report was prepared for the Data Engineering and Analysis (Inżynieria i Analiza Danych) program, Laboratory Group L-4, evaluated by Dr. Paweł Bednarz[cite: 5].

## 📄 File Contents
The report is available in two formats for accessibility and editing purposes:
*   **`project_report_PL.pdf`**: The finalized, non-editable document format containing the theoretical background and mathematical derivations.
*   **`project_report_PL.odt`**: The editable OpenDocument Text version of the same report.

## 📚 Report Scope
The document provides a comprehensive overview of the subject, including:
*   A theoretical introduction to modeling mixing processes using differential equations[cite: 5].
*   Real-world industry applications, such as chemical manufacturing, water purification, gas transformations, and biochemical processes[cite: 5].
*   Detailed, step-by-step mathematical breakdowns of the two core practical examples simulated in the `src/` directory (the continuous brine tank flow and the multi-stage pollutant retention tank)[cite: 5].

*(Note: The documents in this directory are written in Polish).*
