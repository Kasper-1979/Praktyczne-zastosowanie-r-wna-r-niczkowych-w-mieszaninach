# Supplementary Notes

## 📌 Overview
This directory contains supplementary notes, informal documentation, and legacy instructions related to the project's development and laboratory execution. 

## 📄 File Contents
*   **`install_notes_PL.txt`**: The original, informal installation notes written in Polish. It contains raw `pip` commands for installing the required Python dependencies (`numpy`, `scipy`, `matplotlib`, `pillow`). It also includes basic troubleshooting tips intended for the university laboratory environment, such as copying the "green path" if the initial installation fails.

## ⚠️ Important Note
These notes are preserved for historical and academic context. For standard project setup and deployment, please refer to the main documentation and use the **`requirements.txt`** file located in the root directory of this repository:

```bash
pip install -r requirements.txt
```
